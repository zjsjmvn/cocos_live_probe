## 真实 CountRice 验收

预览 `http://127.0.0.1:7456/`，Chrome CDP `http://127.0.0.1:9223`，Creator 3.8.8。从通用工具目录执行：

```powershell
node -r ts-node/register -e "require('../game-extensions/count-rice/browser-smoke.ts')"
```

脚本创建并释放独立 BrowserContext，验收结果：

- 从零触摸起步，通过 61 个步骤、50 次真实触摸完成初始数米引导并达到 `countPower` 2 级；再次请求已达成目标返回 0 步。
- 用仅测试入口预置的短目标等待完成表现，通过正常完成按钮进入 `eatRice`；等待步骤计入预算。
- 屏幕停用移除开发桥，再启用取得不同的桥实例。
- 通过真实鸡商店槽 1 卡片，按快照报价 30 金币使鸡从 1 级到 2 级。未开放的 `riceSlot` 升级目标在输入前拒绝。
- 通过可见的普通领取按钮结算离线收益，待领取状态归零。

测试状态预置通过独立诊断入口完成，不由游戏 MCP 开放。玩家自动玩仍通过真实输入和正常存档路径推进。此次实机证据覆盖 Cocos 3.8.8；其他游戏和引擎版本需各自桥、插件与验收。
