## 边界

- 真实测试覆盖正常 Cocos Canvas 适配与浏览器缩放。直接改变 Canvas CSS transform 而不更新引擎显示/输入适配时，Cocos 自身可能无法命中；探针不会绕过引擎输入。测试只用这种人为变化验证旧几何拒绝，随后恢复并使用公开 screen.windowSize 设置通用场景适配。
- Creator 会将测试主动抛出的异常显示为 DOM 错误面板。测试完成错误采集后移除该测试面板，再继续独立输入检查；探针本身不移除遮挡。
- 一次性 CLI 不提供跨进程日志历史；其他 Cocos 版本、任意 3D 目标、多指输入、性能/帧诊断不属于本轮验收承诺。
