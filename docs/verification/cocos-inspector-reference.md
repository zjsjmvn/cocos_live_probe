# CocosInspector 参考功能与验收

2026-10-11，对照宿主项目安装的 CocosInspector 2.2.3 的界面、组件模板和设置项。下表记录 Cocos Live Probe 的对应入口；实现使用本工具的认证 API、运行实例与队列。

| CocosInspector 能力 | 本工具对应能力 |
| --- | --- |
| 游戏、节点树、属性三栏和分隔线 | 桌面三栏、两条可拖动分隔线、键盘调整 |
| 游戏刷新、暂停、FPS、静音 | 游戏工具栏；刷新节点树独立于重载游戏 |
| 2D / 3D 悬停选取、设计模式 | 左键 2D、右键 3D、运行时拖拽、Esc 撤销当前拖拽 |
| 手机预设、横竖屏、自定义分辨率 | 原有固定预设、旋转、适应窗口；新增命名预设保存和删除，最多 20 项 |
| 节点图标、子节点数量、Prefab 标识 | 节点类型图标、数量；新增 Prefab 根节点标记，图标和数量可分别隐藏 |
| FairyGUI 节点名称 | 可显示节点 `$gobj.name`，保留真实 Cocos 层级及 UUID |
| 节点与组件搜索、完全匹配、排除内建组件 | 树选项中的搜索范围、完全匹配、隐藏内建组件、当前子树；组件标题菜单可搜索同类组件 |
| 节点右键菜单 | UUID、路径、访问代码、打印并存为 `$probeNode`、激活/关闭、移除运行时节点 |
| 组件右键菜单 | UUID、访问代码、打印并存为 `$probeComponent`、场景同类组件搜索 |
| 节点层级拖放 | 拖到目标节点下，保留世界 Transform；服务拒绝根节点移动、父子循环和旧场景凭据 |
| 基础 Transform、Layer、Opacity | Transform 编辑，Layer 和有效透明度读取 |
| 颜色、枚举、向量 | RGBA 数字和 RGB 色板、枚举下拉、Vec2/3/4、Quat、Size、Rect；编辑保留 Cocos 值类型并使用字段 setter |
| 字符串和多行文本 | 基础字符串；包含换行或较长的文本使用 textarea |
| 数组、对象、节点/组件/资源链接 | 有界展开；基础数组元素和数组中的 Cocos 值类型可编辑；节点/组件跳转和资源搜索；普通对象只读 |
| 字段排序、属性对齐、数组自动展开 | 字段排序、属性名左对齐、数组自动展开长度；保留草稿与展开状态 |
| 自动更新树和选中节点 | 自动同步与选中节点属性同步可分别调整；设置保存在当前项目的桌面配置或浏览器面板存储 |
| Cocos 信息与环境开关 | Cocos 页：引擎版本、平台、画布、设计分辨率、DPR、`cc/env` 开关、目标帧率与 Retina |
| DrawCall 分析 | 引擎设备报告的 DrawCall/三角形/实例数；渲染组件、纹理、材质、Mask、Graphics 与文字缓存排查线索 |
| 资源管理入口 | 已加载资源列表，按名称/类型/UUID 搜索，100 项分页，引用计数、纹理尺寸、原生地址、UUID 复制 |
| LocalStorage | 当前游戏存储列表、增加/修改键值、删除；修改必须匹配读取时的值，防止覆盖游戏的新值 |
| 日志筛选、等级、清除、代码控制台 | 新增日志页、等级和文本筛选、跟随最新、清除显示；代码执行、断点和网络检查使用已有 Chromium DevTools |
| 清除 HTTP 缓存、Cookies | 桌面设置中的独立操作，确认后只作用于当前游戏 Session；不重载游戏 |
| 迷你模式 | 桌面设置「简洁模式」，同一原生游戏扩大至整窗；「显示检查面板」恢复 |
| 自定义扩展 | 扩展页读取本工具已配置的项目游戏扩展状态；复用现有只读桥、AI 接入与验收包 |
| Creator 快捷键入口 | 已有项目扩展、Shift+Enter、按项目复用窗口和有效包选择 |

## 能力边界

- Inspector 的属性、层级与节点移除修改运行时内存。存储编辑会写当前游戏的本地存储；缓存清理会删除当前 Session 对应的数据。后两类操作与临时节点编辑的生命周期不同。
- CocosInspector 的「保存回 Prefab / 项目资源」、编辑器资源定位和脚本打开依赖编辑器资源数据库。当前工具没有编辑器资源写回协议，不能把运行时实例 UUID 当作编辑器节点或资源 UUID。
- FairyGUI 支持这里采用可用的运行时名称。没有安装 FairyGUI 时正常显示 Cocos 树；不推断或折叠第三方库内部 Container 层级。
- CocosInspector 的外部商业资源管理插件、任意 JavaScript 扩展文件、代理服务器和禁用 Web 安全设置不构成本工具的运行时 API。项目扩展仍采用已建立的插件协议。
- 本地自定义预览地址继续通过 `COCOS_RUNTIME_PROBE_PREVIEW_URL` 指定。Creator 项目扩展继续查询当前项目的预览地址；此变更不引入远程页面接管或 Creator 构建自动化。
- 渲染表只给出排查因素，不承诺逐节点的真实 DrawCall 或精确合批边界。缺失设备统计或环境模块时显示未提供，不用节点数量推算。
- 数组每层最多显示 40 项、嵌套最多 3 层。不可写字段、普通对象成员、循环引用和被截断的长文本不能编辑。资源最多查询前 20000 项。存储最多显示 200 项，每项值最多 16384 字符，总显示内容有界；截断项不能覆盖。
- 日志只涵盖当前服务连接，沿用 1000 条 / 2 MiB 缓冲容量。清除显示保留后台诊断和取证记录；淘汰会显示缺口。

## 验收入口

- `npm run typecheck` 与 `npm test`：类型、认证接口、值类型、数组编辑、枚举限制、旧场景拒绝、存储冲突、资源分页和容量。
- `npm run test:inspector:browser`：真实 Cocos 3.8.8 的颜色/Alpha、枚举、数组、引用、组件搜索、层级拖放、引擎信息、目标帧率、资源、存储冲突、日志、菜单与节点移除；沿用旧面板的草稿、键盘、配色、同步与生命周期验收。
- `npm run test:inspector:desktop`：同一组真实引擎能力，加上原生游戏、AI/CLI 接入、DevTools、暂停保留、分辨率、最小窗口、简洁模式和实际窗口截图。
- `npm run test:inspector:packaged`：先核对包内新增代码和界面资源与当前构建一致，再运行同一套桌面验收，避免旧包携带旧测试而误报通过。

实际窗口截图写入系统临时目录：`cocos-live-inspector-workbench-fields.png`、`cocos-live-inspector-workbench-info.png`、`cocos-live-inspector-workbench-assets.png`、`cocos-live-inspector-workbench-logs.png`。测试使用独立运行实例和测试节点，不修改人工窗口的游戏、存储或暂停状态。
